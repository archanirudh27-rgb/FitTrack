# FitTrack

A personal, multi-user fitness tracking web app.

## V1 product direction

FitTrack combines strength training and cycling in one personal fitness dashboard.

### Strength
- Exercise library with muscle groups, instructions, tutorials and personalised imagery
- Custom workout templates
- Weekly/monthly workout planning
- Per-session overrides for sets, reps, target weight and rest time
- Frozen planned-session snapshots
- Set-by-set completion with one-tap logging
- Rest timer
- Workout history, PRs, volume and progression

### Cycling
- GPS ride tracking
- Distance, duration and speed
- Route tracking
- Estimated calories
- Ride history and cycling progression

### Platform
- Multi-user architecture from day one
- Private user data by default
- GitHub-backed application code
- Supabase-backed data and storage
- Mobile-first PWA

## Visual direction

FitTrack uses a dark, premium, data-first visual language inspired by modern cycling trackers:

- Near-black charcoal backgrounds
- Warm performance orange as the primary accent
- White and cool-grey typography
- Dark elevated cards
- Large, glanceable performance metrics
- Minimal, restrained use of colour
- Cycling GPS routes highlighted with warm orange/amber

The design system is intentionally themeable so colours, typography, spacing, cards and navigation can be redesigned later without changing the underlying application logic or data model.

## Status

Initial foundation phase. Database architecture, app shell and core workout/cycling workflows are being developed incrementally.
